# 仓库结构与保留范围

## 当前维护内容

| 目录 | 内容 |
| --- | --- |
| `src/` | Refine、Expert、Harness、用户交互、预算接口、缓存绑定，以及可选记忆与追踪集成 |
| `web/` | 工作台、历史流程图、评分、Card、边界问答及前端测试 |
| `scripts/` | 启动、导入、恢复、检查和仍可调用的实验入口 |
| `test/` | 离线回归测试与小型去凭据夹具 |
| `.pi/skills/` | 五个保留的操作 Skill：Refine Agent、Workflow、Harness 审查及两种 Expert Replay 操作说明；不是运行缓存 |
| `docs/assets/` | README GIF 和静态封面 |
| `sidecar/` | 可选 Acontext 本地部署模板 |

源代码中保留旧 Refine Agent、回放恢复、Profile 和 Phoenix 模块：当前测试或入口仍依赖这些接口。未注册为产品工具不等于可以删除。底层运行库、旧导入别名和序列化字段继续兼容。

## 不进入发布仓库

`validation/`、`.refine-console/`、`.pi/` 下的运行数据、会话、预算账本、provider trace、反馈、模型缓存、凭据和本地服务数据都留在本机。内置 `.pi/skills/` 有明确白名单。历史文稿可能包含用户内容，未随源码发布。

本次整理移出九个早期实验脚本：成对文稿 / Word 生成、Phoenix 实验串联与旧验收，以及两项 policy 评审。它们只在旧脚本组内互相调用，不是现行 Refine 或多案例 Harness 的入口。对应 npm 命令同步移除；可选 Phoenix 源码集成没有删除。

二十份早期方案、实验日志和 worktree 交接文档移出当前文档入口。本机保存逐文件 SHA-256 归档及清理清单，可以恢复。原始实验、最近注册的预设和预算来源没有移动；其他 Git worktree 未按时间或名字盲删。

## 发布检查

`npm run check:release` 检查准备发布的文件：拒绝运行数据、凭据文件、个人绝对路径、异常大文件、丢失的 npm 入口和失效的本地 Markdown 链接，并扫描常见密钥形式。它不打印疑似密钥内容，也不能替代人工审阅或专用秘密扫描。

发布目录是当前清理后文件的独立 Git 快照，不带原实验仓库历史，不重置或改写原 worktree。新克隆需要重新配置凭据、导入私有历史和准备任务。
